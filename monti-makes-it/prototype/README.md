# The prototype

Open `monti-prototype.html` in any browser. That's it — no install, no server, no
network. Everything runs in the page.

| Sign in as | Password |
|---|---|
| `Tyler1` | `Tyler1` |
| `client1` … `client5` | `client` |

There are also two shortcut buttons in the bar across the top of the page.

**What it is for:** showing someone the whole product in two minutes. Every screen is
real and clickable — the landing page, both forms, a member portal with checkout, and
the admin portal with revenue, incoming quotes, CRM and the tagged catalog.

**What it is not:** the product. The data is generated, state is in memory (a refresh
resets it), payments are simulated, and there is no real authentication — anyone with
the file can open any portal. Don't put a client in front of it and call it their
account.

The deployable version is in `../engine`.
