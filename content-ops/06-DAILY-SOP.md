# Daily SOP — The 90 Minute Block

This is the job. Same time every day. The compounding comes from the fact that
it is boring and repeated, not from any individual post.

## Block 1 — Recon (15 min)

- [ ] Check yesterday's posts. Record in `tools/tracker.csv`: views, 3s retention,
      avg watch %, follows, comments.
- [ ] Identify yesterday's best and worst hook. One sentence each on why.
- [ ] Scan TikTok Creative Center / trending audio for the niche. Note 2–3 sounds
      or formats with rising velocity — **rising**, not peaked. A trend at peak is
      already too late.
- [ ] Read comments on the top post. Pull one question or objection — it's
      tomorrow's script.

## Block 2 — Write (25 min)

- [ ] Pick 3 ideas: one from comments, one from trend recon, one from the backlog.
- [ ] For each: write **3 hooks** from different families (`02-HOOK-ENGINE.md`).
- [ ] Write the beat sheet — one line per 5 seconds. If a beat doesn't advance
      the loop or land, cut it.
- [ ] Write the loop-back or the hard-stop final line.
- [ ] Write per-platform captions.

## Block 3 — Produce (30 min)

- [ ] Record VO or assemble assets.
- [ ] Cut. Rule: a visual change every 5–7 seconds minimum.
- [ ] Burn in captions. Check the safe zones per platform.
- [ ] Watch it once at full attention. **Cut the most boring 2 seconds.** There is
      always a most boring 2 seconds. Do this every single time.
- [ ] Export clean — no watermarks.

## Block 4 — Publish (15 min)

- [ ] Upload natively to each platform, staggered 2–4 hours.
- [ ] Platform-specific caption + hashtags.
- [ ] Log post IDs into the tracker.

## Block 5 — Engage (15 min)

- [ ] Reply to every comment in the first hour on new posts. Early comment
      velocity is a ranking input on every platform here.
- [ ] Pin the comment that best re-states the hook or opens a debate.
- [ ] Comment on 5 larger accounts in the niche. Not "great post" — an actual
      take. This is a real discovery channel and it's free.

## Weekly (Sunday, +60 min)

- [ ] Tracker review. Which hook families won? Which died?
- [ ] Kill the bottom-performing format. Double the top one.
- [ ] Bank next week's ideas — target 20 in the backlog.
- [ ] Record and cut one long-form for the extraction pipeline.
- [ ] Check for policy notices/strikes on all five accounts.

## The rules that keep it alive

1. **Post every day.** Consistency is a ranking input and a skill-building
   mechanism. A mediocre post today beats a great post Thursday.
2. **The tracker is not optional.** Without it you're guessing, and after 90 days
   of guessing you'll know nothing. With it, you'll have a personal playbook that
   beats every generic guide including this one.
3. **30 days before judging a format.** Under 30 posts, variance dominates signal.
4. **One controlled variable at a time.** Change the hook OR the format OR the
   length. Not all three.
5. **Never delete a flop** unless it violates policy. Deleting sends a quality
   signal to the account.
6. **Ideas get banked, not chased.** Never sit down to a blank page — the backlog
   is filled during recon, not during writing.

## Optional: gate the day

The `unlazy` skill can turn this checklist into a `GATES.md` with runnable checks
(files exist, N scripts written, tracker rows appended for today's date), so a
day can't be reported as done when it isn't. Worth wiring up once the cadence is
established and slipping is the actual risk.
