## Immutability
  UPDATE/DELETE statements against ledger_entries in monti/: 2
    monti/ledger.py:147  execute("UPDATE ledger_entries SET status = 'SETTLED', occurred_at = ? WHERE id = ?",
    monti/ledger.py:159  execute("UPDATE ledger_entries SET status = 'FAILED', note = ? WHERE id = ?",
  Both transition a PENDING row to SETTLED or FAILED — a pending payment
  resolving, not an issued receipt being edited. Corrections to settled money
  go through ledger.reverse, which writes a linked reversing row. The clause
  below therefore rests on an argument, not on an absence, and Phase 16 must
  prove it rather than inherit it.
  ledger.reverse present: True — corrections as linked reversing rows
