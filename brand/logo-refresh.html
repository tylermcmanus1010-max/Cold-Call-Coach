The current JPEG carries its own white box, so it can only ever sit on a white page. This one is transparent — which is what makes a shirt, a van wrap or a dark website possible at all. Two blues disappear on a dark ground, so there is a reversed single-colour version for those, which is the pair every logo needs.

In the place it was actually a problem

Swinley Spa Call
His current logo is a stacked mark — the name sits inside the artwork. In a 64px header bar that text renders about 4px tall, so his website header has to set the name in type instead. The compact droplet plus the wordmark solves it, and it is the same brand either way.

What changed

  • Vector, not a photo of a logo. 2 KB, sharp at any size, transparent behind.
  • The droplet lost its gloss. The hard white specular highlight dated it; a single clean gradient in the same two blues replaces it.
  • The wrenches read as wrenches. In the original they sit pale behind the type and blur into a smudge. Here they are clear of the droplet, with open jaws and hex ring ends.
  • The curved tagline is set straight. Type on an arc is the single thing that most makes a logo look homemade — and it is unreadable small.
  • A compact mark exists. For anywhere the full lockup cannot survive.
  • So does a reversed one. White, for dark shirts, van wraps and anything not printed on white paper.

Before this gets used

The wordmark here is set in EB Garamond, which is close to his existing letterforms but not identical. For final files it should be converted to outlines so the logo never depends on a font being installed. If Seth likes the direction, that is a half-hour of work — and worth doing before anything gets printed.
